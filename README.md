I ship open-source agent skills and brutally simple dev tools. Everything checked against sources, everything free to inspect.

Right now most of my time goes into [bullshit-detector](https://github.com/SerhiiKorniienko/bullshit-detector) - agent skills that fact-check the internet. You throw it a link (YouTube, TikTok, article, PDF, plain text) and ask if it's true. It pulls the content, splits it into individual claims, verifies each one with web search, and returns a report with per-claim verdicts, sources, and a 0-10 score. Main rule: no source, no verdict - the model is not allowed to call something true from memory. MIT, no API keys, works with any agent.
